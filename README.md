# Django Practical Project

Учебный проект на Django, включающий в себя несколько приложений (`shopapp`, `blogapp`, `myauth`). В проекте реализована валидация данных, кастомная загрузка нескольких файлов, а также настроена контейнеризация с помощью Docker и управление зависимостями через Poetry.

## 🛠️ Стек технологий
* **Python 3.11+**
* **Django 4.2**
* **Poetry** (управление зависимостями)
* **Docker / Docker Compose** (контейнеризация)

## 🚀 Запуск проекта локально (без Docker)

Для локального запуска вам понадобится установленный Python и Poetry.
